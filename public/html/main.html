ABOUT THIS BUILD

This is a full-stack e-commerce portfolio project
showcasing modern web development skills.
Built from scratch using a Wix template as
design inspiration, this site demonstrates
real-world functionality and clean code practices.

TECH STACK

Frontend: AngularJS, HTML5, CSS3, jQuery
Backend: Node.js, Express.js
Database: MongoDB with Mongoose ODM
Payments: Stripe API integration
Email: Nodemailer for contact forms

KEY FEATURES

• Dynamic shopping cart with add/remove functionality
• Product wishlist system
• Real-time cart updates and totals
• Responsive design (mobile-first)
• Secure payment processing (test mode)
• User profiles and authentication (demo mode)

Note: OAuth authentication is disabled for portfolio safety.
All features are fully functional in demo mode.
